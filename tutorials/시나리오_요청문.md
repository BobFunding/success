# 장면 표 요청문 (다른 AI 채팅에 붙여 넣기)

키 없이도 쓰는 방법입니다. 아래 상자 안의 글을 ChatGPT·Gemini·Claude 같은 AI 채팅에 붙여 넣고, `<<…>>` 부분만 바꾸세요.
AI가 써 준 장면 표를 `scenario.yaml` 로 저장해 튜토리얼 메이커 시작 화면의 [📥 공유 파일 가져오기] 대신
`output/tutorial/<이름>/scenario.yaml` 에 두거나, `python tutorial.py check <파일>` 로 리허설해 보세요.

```text
너는 웹사이트 사용법 영상의 '장면 표'를 쓰는 도우미야. 아래 사이트에서 <<무엇을 하는 방법>>을 보여 주는 장면 표를 YAML 로 써 줘.
사이트: <<https://…>>
화면 설명(내가 본 순서대로): <<예: 첫 화면 오른쪽 위 '로그인' 버튼 → 로그인 화면 아래 '회원가입' → 이름·휴대전화 칸 → '저장'>>

규칙
- 키 이름은 한국어 그대로: 제목, 주소, 브랜드, 시작상태, 단계이름, 개인정보칸, 장면(단계, 말, 동작, 대상, 값, 칸, 목록, 버튼), 인트로, 아웃트로
- 동작은 클릭 / 입력 / 선택 / 체크 / 스크롤 / 마우스올리기 / 보여주기 / 대기 중 하나
- 대상은 화면에 보이는 글자 그대로(버튼 글자, 칸 이름). 모르면 비워 두고 '확인 필요'라고 적어 줘
- 문장(말) 하나에 동작 하나. 존댓말, 짧게, 숨 쉬는 자리에 쉼표. 첫 장면은 "먼저, ", 마지막은 "마지막으로, … 끝이에요."
- 비밀번호 값은 "@보관함", 인증번호처럼 그때그때 다른 값은 "@물어보기:인증번호를 적어 주세요"
- 이름·전화·이메일은 '홍길동', '01012345678', 'test@example.com' 같은 테스트 값만. 개인정보칸에 그 칸 이름을 넣어 줘
- 단계는 3개 안팎으로 묶고 단계이름에 짧은 이름. 제목은 "<<주제>>, N단계면 끝!"
- 인트로 2문장(인사, "오늘은 … 방법을, N 단계로 알려 드릴게요."), 아웃트로 2문장
- 결제·탈퇴·삭제·실제 발송 장면은 넣지 마
```

예시 장면 표: `tutorials/ep1/scenario.yaml` (태권월드 관장님 회원가입), 형식 설명: `tutorials/DESIGN.md` 4절.
