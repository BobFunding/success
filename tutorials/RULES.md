# 태권월드 튜토리얼 제작 규칙서

태권월드(https://taekwonworld.net) 사용법 튜토리얼 시리즈를 만드는 규칙과 방법입니다.
어떤 AI 도구(Claude, Codex 등)로 이어서 만들더라도 **이 문서를 그대로 따라** 같은 형식·품질이 나와야 합니다.
1편(관장님 회원가입)이 이 규칙으로 완성된 기준 작품입니다. 스크립트는 `tutorials/ep1/`.

## 0. 기본 방식 (가장 중요)

- **사용자가 녹화한 영상을 편집하는 방식이 아닙니다. AI가 직접 브라우저로 사이트에 접속해 조작하며 녹화하고, 편집까지 끝냅니다.**
- 순서: 화면 파악 → 대본 → 나레이션 생성 → 나레이션 길이에 맞춰 녹화 → 편집·합성 → 프레임 검수 → 사용자 피드백.
- **나레이션을 먼저 만들고 화면을 거기에 맞춥니다.** 목소리를 늘이거나 줄여서 화면에 맞추지 않습니다(속도 조절은 ±5% 이내).
- 사용자에게 진행 전 계획(대본, 장면 구성)을 먼저 보여 주고 확인받습니다. 사용자가 "아직 실행하지 말라"고 하면 실행하지 않습니다.

## 1. 목표와 시청자

- 시청자: 태권월드를 처음 쓰는 **도장 관장님**(그 외 사범님·학부모 편은 해당 대상).
- 목표: 영상을 보며 **그대로 따라 하면** 기능을 쓸 수 있게. 그리고 **"절차가 복잡하지 않다"**는 느낌.
- 홍보 영상처럼 빠르고 화려하게 만들지 않습니다. 차분하게, 누를 곳이 분명하게.

## 2. 영상 구성

- **한 편 = 기능 하나**, 길이 **1분 30초 안팎**(최대 2~3분). 길면 말로 안 해도 되는 설명을 화면 글자로 돌려 줄인다. 따라 하기 어려운 단계(버튼 찾기, 인증)는 줄이지 않는다.
- **인트로(약 10초, 모든 편 공통 틀)**: 브랜드 배경 → 로고 → 제목("○○○, N단계면 끝!") → 단계 카드 N장 등장.
  나레이션: "안녕하세요, 태권 월드입니다." / "오늘은 ○○○ 방법을, N단계로 알려 드릴게요."
- **본편**: 단계 3개 안팎. 왼쪽 위 진행 표시 `1/3 단계이름`.
- **아웃트로(약 10~12초, 공통 틀)**: "오늘 배운 N단계" 카드에 체크 표시 → 다음 편 안내 → 로고.
  나레이션: "오늘 배운 N단계, 기억하시죠?" / "다음 영상에서는 ○○○ 방법을 알려 드릴게요. 태권 월드였습니다."

## 3. 대본 규칙

- 문장 하나 = 화면 동작 하나. 짧고 말하듯이.
- **화면에 보이는 글자 그대로** 부른다("로그인 관장 버튼", "회원가입 버튼", "등록 버튼").
- 어려운 말 대신 쉬운 말("필수 항목" → "꼭 적어야 하는 칸").
- 막힐 만한 곳에 안심 문장 한마디("처음 한 번만 하면 돼요", "하나씩 채우면 금방이에요").
- 꼭 필요한 단계는 빼지 않는다(빼면 따라 하다 막힌다). 그대로 두는 칸(국가 등)은 말 대신 화면 글자로.
- 표기: 브랜드는 대본에 **"태권 월드"**로 띄어 쓴다("태권월드"는 "태권널드"로 들림). 자막에는 "태권월드"로 표기.
- 숨 쉬는 자리에 쉼표를 넣는다.

## 4. 나레이션 (목소리)

- 사용자 본인 목소리가 아닌 **AI 음성**: edge-tts `ko-KR-HyunsuMultilingualNeural`(현수), **차분 버전 = 속도 -8%** (사용자 선택).
- 생성·다듬기: `autoedit/narration.py` (`synthesize`, `build_track`).
  - 문장마다 속도·높낮이를 ±1~3 정도 다르게(기계적인 느낌 줄이기).
  - 앞뒤 완전 무음(-65dB)만 정리하고 **끝음절 꼬리는 자르지 않는다**(자르면 끝이 흐려짐 — 사용자 지적).
  - 음향: 80Hz 이하 제거, 280Hz +1.2dB(편안한 중저음), 3.5kHz +2dB(또렷함), 압축, -14 LUFS. 문장 사이는 아주 작은 방 소리.
  - 문장 사이 쉼 약 0.45~0.55초, "눌러 주세요" 뒤는 따라 할 시간만큼 조금 길게.
- 생성 후 받아쓰기(Whisper)로 다시 받아 적어 발음이 정확한지 확인한다.
- 상업적 사용 전 Microsoft 음성 이용 조건 확인(사용자에게 알림).

## 5. 화면 연출

- 배경: 남청 → 브랜드 파랑 그라데이션 `#1B2559 → #405BEA`, 둥근 모서리 창 + 그림자 (`autoedit/screenfx.py`).
- 강조색: 로고 빨강 `#CC1424` (클릭 파동, "처음 한 번만!" 같은 말풍선). 편마다 포인트 색 하나(1편 하늘 `#54B4CC`)를 단계 번호·진행 표시에.
- 확대: 클릭 위치와 **클릭 결과로 바뀐 곳**이 함께 보이게(누른 버튼만 확대하지 않는다). 배율 1.6 안팎, 최대 2.0.
- 디밍: 지금 누를 곳만 밝게, 나머지는 30% 어둡게(더 어두우면 흰 화면이 탁해 보임).
- 커서: 누를 곳으로 곧장 이동(두리번거리지 않음) → 클릭 직전 잠깐 멈춤 → 문장 끝 무렵 클릭.
- 로딩 화면은 잘라낸다. 결과 화면은 1~2초 유지.
- 자막: 화면 아래, 흰 글씨 + 반투명 남청 상자, 나레이션과 같은 문장.

## 6. 개인정보·안전 규칙 (반드시)

- **실제 원생·회원 정보가 화면에 나오면 안 된다.** 데모 계정·데모 값만 쓴다(1편 아이디 `taekwon_demo`).
- 이름·휴대전화·인증번호·생년월일·성별 등은 **녹화할 때부터** CSS 로 글자를 흐리게(투명 글자 + 흐린 그림자) 해서 원본에도 값이 남지 않게 한다. 모자이크가 덕지덕지 붙은 느낌이 아니라 자연스럽게.
- **실제로 저장되거나 밖으로 나가는 동작**(가입 등록, 원생 등록·삭제, 문자·알림 발송, 결제)은 **사용자 확인 없이 실행하지 않는다.** 확인 전에는 해당 화면에서 xhr/fetch 요청을 막아 둔 채 클릭 장면만 찍는다. 실제 결제·학부모 알림 발송은 하지 않는다.
- 로그인 정보는 채팅이나 코드에 쓰지 않는다(실행 환경의 비밀 설정/환경변수로).
- 휴대폰 문자 인증이 필요한 순간은 사용자 도움을 받는다.

## 7. 녹화 기술 (1편에서 검증한 방법, Linux 기준)

- 가상 화면 Xvfb 2880x1620, Chromium `launch_persistent_context` 의 **기본 창** + `--kiosk` + `--window-size=1920,1080`(CSS 기준) + `--force-device-scale-factor=1.5`, `ignore_default_args=["--enable-automation"]`.
  - 새 컨텍스트 창을 쓰면 전체 화면이 안 되고 주소창이 찍힌다. 창 크기를 화면 픽셀로 주면 페이지가 작게 그려진다.
- 캡처: `ffmpeg -f x11grab -framerate 30 -video_size 2880x1620 -draw_mouse 0` 무손실(libx264rgb crf 0).
- 커서는 페이지에 직접 그린다(init script). 클릭 시각·좌표, 문장 시작 시각을 기록한다.
- 시작 직후 화면을 0.3초 검게 해서 동기 표시를 남기고, 영상에서 그 프레임을 찾아 기록 시각과 맞춘다.
- 녹화 전 반드시 **리허설**(헤드리스, 녹화 없이)로 모든 조작이 되는지 확인한다.
- 이 환경처럼 보안 프록시가 있으면 Chromium 에 프록시 CA 를 등록해야 한다(`certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n proxy -i <CA>`). TLS 검증을 끄지 않는다.
- Windows·Mac 은 튜토리얼 메이커(`튜토리얼.bat`)가 "한 장씩 찍기"로 녹화한다(`autoedit/tutorial/capture.py`, 모니터 크기와 무관). 실기 확인은 아직.

## 8. 출력

- 유튜브 업로드용: **2560x1440, 60fps**, H.264 High, CRF 16, 키프레임 2초, BT.709, AAC 48kHz 320kbps.
- 사본: 1920x1080, 30fps, 16Mbps(최대 20Mbps).
- 함께 제공: 자막 `.srt`, 유튜브 챕터 목록.
- 세로형(쇼츠)은 본편 확정 뒤 핵심 장면만 따로.

## 9. 검수 체크리스트 (보내기 전에)

튜토리얼 메이커는 아래를 만들기 끝에 자동으로 확인합니다(`autoedit/tutorial/qa.py`, 결과 `qa.json`·장면별 사진 `qa_scenes.jpg`). 사람은 ⚠ 항목만 보면 됩니다.


- [ ] 프레임을 뽑아 확인: 주소창·브라우저 테두리가 안 보이는지, 화면 배율이 맞는지
- [ ] 디밍·클릭 파동 위치가 실제 버튼과 맞는지
- [ ] 개인정보 칸이 처음부터 끝까지 흐린지(실제 값 노출 0)
- [ ] 자막 오타, 단계 표시가 맞는 구간에 나오는지
- [ ] 영상·오디오 길이 일치, 나레이션과 클릭 시각이 맞는지
- [ ] 의도치 않은 오류 메시지가 화면에 없는지(입력 중 사이트의 원래 안내 문구는 괜찮음)
