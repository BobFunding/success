## 0. 기준 (가장 중요, 절대 엇나가지 않기)

> **1편(태권월드 관장님 회원가입) 때 Claude가 사이트에 직접 접속해 클릭·타이핑하며 녹화하고 편집한 방식을, 같은 품질 그대로 프로그램으로 만든다.**

- 1편에 들어간 기능은 **하나도 빠짐없이** 넣는다(1.1 표). 어느 모듈에서 처음 만들었는지는 상관없다.
- 나머지는 모두 이 기준 위에 얹는 **추가 기능**이다. 추가 기능은 기준을 건드리지 못하게 분리한다(완성된 결과를 받아 따로 처리하는 부품). 추가 기능이 고장 나도 기본 영상은 나와야 한다.
- **완료 판정**: 프로그램으로 1편을 다시 만들어 기존 1편과 같은 시각의 프레임·길이·챕터·자막·클릭 위치를 비교해 같아야 한다. 이 검사를 통과하기 전에는 추가 기능을 붙이지 않는다.
- 이후 무엇을 고치든 이 1편 재현 검사를 다시 돌린다. 결과가 달라지면 그 변경은 받지 않는다.
- 기존 편집기(`app.py`, `web.bat`, `autoedit/pipeline.py` 등 말하는 영상 편집)는 **건드리지 않는다.** 튜토리얼 메이커는 별도 프로그램이다. 부품(모듈)만 가져다 쓴다.

## 0.1 사용 편의가 기본 조건 (모든 결정의 우선 기준)

사용자 요구: "무조건 조건은 사용자가 사용하기 편한 것." 기능을 더할 때마다 아래를 먼저 지킨다. 지키지 못하면 기능을 숨기거나(고급·더 고르기) 빼는 쪽을 택한다.

1. **아무것도 안 건드려도 끝까지 간다.** 모든 선택에 추천값. 기본 경로: 주소 → [한 번 해 보이기]·[■ 끝] 또는 [AI에게 맡기기] → [다음] → [만들기 →] → [결과 보기] → [내보내기].
2. **한 화면에 주 버튼 하나.** 다음에 무엇을 누를지 항상 하나만 파랗게.
3. **보여 줄 것과 숨길 것을 나눈다.** 화면에 바로 보이는 선택은 단계당 2~3개(선택 단계: 목소리·영상 모양·꾸미기). 나머지는 "더 고르기"·"자세히 보기"·"고급 설정"에 접어 둔다.
4. **한 번 정한 건 다시 묻지 않는다.** 브랜드, 규칙, 키, 비밀번호, 올릴 곳.
5. **설정은 한 곳에.** 오른쪽 위 ⚙ 설정 하나에 탭 두 개: **브랜드**(모양과 목소리) / **규칙**(길이와 문장). 화질 등 드문 항목은 브랜드 탭의 고급 설정 안.
6. **사람이 봐야 할 것만 알린다.** 정상 항목은 한 줄 요약(✓ 26개 준비됨), 확인이 필요한 것만 ⚠ + 해결 버튼 하나.
7. **쉬운 말, 같은 말.** 아래 용어표의 말만 쓴다. 같은 것을 두 이름으로 부르지 않는다.
8. **되돌릴 수 있다.** 지운 장면 되살리기, [1편 기준으로 되돌리기].
9. **사용자가 빠뜨린 것은 만드는 쪽이 챙긴다.** 사용자는 다 말하지 못한다. 구현하는 AI·개발자는 1편 경험과 이 문서를 기준으로 빠진 것을 찾아 제안하고, 사용 편의를 해치지 않는 방식(기본값·자동·접어 두기)으로 넣는다.

## 1. 목표와 범위

- 누구든, 어떤 직종이든, **웹브라우저로 쓰는 사이트라면 어디든** 사용법 영상을 만든다.
- 쓰는 사람은 **사이트 주소 → [한 번 해 보이기] 또는 [AI에게 맡기기] → [다음] 몇 번 → 완성.**
- 완성 후에는 Claude 없이, 사용자 PC에서, AI 비용 없이 돈다(AI 도우미만 선택적으로 비용 발생).

## 2. 사용 흐름 (사용자 관점)

1. **설치(처음 한 번)**: `setup.bat`(Windows) / `setup.sh`(Mac·Linux) 더블클릭. Python, ffmpeg, Chromium, 받아쓰기 모델 설치.
2. **실행**: `튜토리얼.bat` / `튜토리얼.command`(Mac) / `tutorial.sh`(Linux) → PC 안에서만 열리는 웹 화면이 브라우저에 뜬다. 검은 창은 켜 둔다.
3. **시작**: 사이트 주소(필수), 영상 제목(비우면 자동 제안).
   - **한 번 해 보이기**: 뜬 브라우저에서 평소처럼 한 번 한다. 화면은 찍지 않고 동작만 기록한다. 손 떨림·머뭇거림은 버려진다.
   - **AI에게 맡기기**: "관장님이 로그인하는 방법"처럼 한 줄 적으면 AI가 사이트를 둘러보고 장면 표를 채운다(11절).
4. **확인**: 자동으로 만든 장면 표(할 말·동작·누른 곳·리허설 결과). 문장을 눌러 바로 고친다. 단계 묶음, 개인정보 칸, 발음 경고가 함께 보인다.
5. **선택**: 바로 보이는 것은 목소리(▶ 실제 첫 문장으로 미리 듣기), 영상 모양(가로/세로/둘 다), 꾸미기(우리 브랜드/기본/참고 영상 스타일) 세 가지. 말 빠르기·자막·배경음악은 "더 고르기"에 접어 둠. 추천값 미리 선택.
6. **만들기**: 목소리 → 리허설 → 자동 녹화 → 화면 연출 → 인트로·자막 → 출력. 진행 상황 표시. 녹화 중에는 마우스를 건드리지 말라는 안내.
7. **결과·내보내기**: 완성 영상, 파일 목록, 폴더 열기. 올릴 곳을 고르면 필요한 파일과 글이 자동으로 준비된다(8절).
8. **다시 만들기**: 지난 작업 목록에서 열어 문장 하나만 고치고 다시 만들 수 있다.

## 3. 화면 설계

- 화면은 Gradio가 아니라 **직접 만든 웹페이지(HTML/CSS/JS) + 로컬 Python 서버**. Gradio는 배치·여백을 거의 조절할 수 없어서 기존 화면이 엉망이었다.
- **격자**: 12칸. 왼쪽 단계 메뉴 3칸(시작·확인·선택·만들기·결과/내보내기), 오른쪽 작업 영역 9칸. 휴대폰 폭에서는 단계 메뉴가 위쪽 가로 줄로.
- **간격**: 8px 단위만(8/16/24/32). 카드 안 여백 24, 카드 사이 16, 구역 사이 32.
- **카드**: 카드 하나 = 일 하나. 제목·설명 한 줄·내용·버튼 위치를 통일.
- **버튼**: 한 화면에 주 버튼(파랑) 하나, 오른쪽 아래 고정. 나머지는 옅은 버튼.
- **글자**: 크기 3단계(제목/본문/보조). 브랜드 색은 강조에만.
- **쉬운 말**: "셀렉터"→"누를 곳", "렌더링"→"만들기". 모든 칸에 회색 예시 글씨와 ⓘ 한 줄 설명.
- **오류는 사람 말로, 그 자리에**: "3번 장면의 '중복확인' 버튼을 찾지 못했어요. 버튼 글자가 바뀌었는지 확인해 주세요." 해당 줄을 빨갛게.
- **빈 화면 금지**: 처음 열면 1편 예시가 채워진 상태로 시작(예시라고 표시).
- **처음 쓰는 사람 30초 안내**: 말풍선으로 순서 안내, 다음부터 안 나옴.
- **정보 표시는 접어 둠**: "자동으로 챙기는 것"은 한 줄 요약 + [자세히 보기]. 사람이 볼 것은 ⚠ 확인 필요 항목뿐이고, 버튼 하나로 해결.
- **한 번 정한 건 다시 묻지 않음**: 브랜드, API 키, 비밀번호, 올릴 곳 기억.
- 장면 표는 처음 쓰는 사람에게는 숨기지 않되(확인 단계), 동작·누른 곳 칸은 시연/AI가 채우고 사람은 "할 말"만 다듬는 구조. 장면 순서는 끌어서 바꾸고, 지운 장면은 되살릴 수 있다.

## 4. 장면 표 (시나리오) 형식

장면 표 = 프로그램이 읽는 "악보". 화면의 표와 파일(`scenario.yaml`)은 같은 내용이다.

```yaml
제목: 관장님 회원가입, 3단계면 끝!
주소: https://taekwonworld.net/
브랜드: 태권월드
시작상태: 로그아웃          # 또는 로그인 (로그인은 녹화하지 않고 미리 해 둠)
단계이름: [가입 화면 찾기, 정보 입력하기, 동의하고 등록]
개인정보칸: [이름, 휴대전화, 인증번호, 생년월일, 성별]   # 자동 감지 + 수동 추가
요청차단: 가입 양식부터
장면:
  - 단계: 1
    말: 먼저, 첫 화면 오른쪽에 있는, 로그인 관장 버튼을 눌러 주세요.
    동작: 클릭            # 클릭 / 입력 / 선택 / 체크 / 스크롤 / 마우스올리기 / 보여주기 / 대기
    대상: 로그인(관장)     # 화면에 보이는 글자 기준. 내부적으로 셀렉터도 함께 저장
  - 단계: 2
    말: 사용할 아이디를 적어 주세요.
    동작: 입력
    대상: 아이디
    값: taekwon_demo
  - 단계: 2
    말: 비밀번호를 적어 주세요.
    동작: 입력
    대상: 비밀번호
    값: "@보관함:taekwon_demo"   # 비밀번호는 표에 쓰지 않음
    말풍선: 처음 한 번만!
    강조: [아이디, 비밀번호]     # 디밍 범위 직접 지정(없으면 대상 기준)
    쉼: 1.5                     # 따라 할 시간
```

- **한 번 해 보이기 → 장면 표**: 누른 요소의 보이는 글자·라벨·역할(버튼/입력칸)과 셀렉터 후보를 함께 저장. 같은 동작의 연속 입력은 하나로 합침. 머뭇거림·잘못 누른 뒤 되돌린 동작은 정리.
- **문장 자동 생성(AI 없이)**: 동작별 문장 틀 + 대상 글자. 예: 클릭 → "○○ 버튼을 눌러 주세요.", 입력 → "○○을(를) 적어 주세요."(받침에 따라 조사 선택), 첫 장면 "먼저, ", 마지막 "마지막으로, … 끝이에요." 말투(차분/친근/전문)마다 틀 세트.
- **표에 그대로 연결**: 순서 = 재현 순서, 누른 곳 = 찾아 누를 글자, 할 말 = 나레이션·자막. 할 말을 고쳐도 조작은 그대로.

## 5. 녹화

### 5.1 두 번에 나눠 진행
1. **한 번 해 보이기(기록만)**: Playwright로 브라우저를 띄우고, 페이지에 이벤트 기록 스크립트를 넣어 클릭·입력·선택을 받아 적는다. 영상은 찍지 않는다. (Playwright codegen 의 기록 방식 참고)
2. **자동 녹화(영상용, 1편 방식)**: [만들기] 시 프로그램이 처음부터 다시 조작하며 찍는다.

### 5.2 자동 녹화 순서
1. 나레이션 생성, 문장별 길이 측정
2. 리허설(헤드리스, 녹화 없음): 모든 대상을 찾는지 확인. 못 찾으면 멈추고 그 장면 표시
3. 고정 크기 창(모니터와 무관), 개인정보 흐림 CSS·요청 차단·팝업 닫기 적용, 시작 시 0.3초 검은 화면(동기 표시)
4. 장면마다: 나레이션 길이만큼 시간을 쓰며 커서 이동(곧장, 부드럽게) → 클릭 직전 멈춤 → 문장 끝 무렵 클릭 / 한 글자씩 입력. 클릭 시각·좌표·대상 상자 기록
5. 창 닫고 편집으로

### 5.3 화면 캡처 방식
- 1편은 Linux 전용(Xvfb + ffmpeg x11grab, 무손실). 프로그램은 **운영체제와 무관한 방식**을 쓴다: Chromium 개발자 도구 프로토콜(CDP) 화면 전송(`Page.startScreencast`) 또는 프레임 단위 캡처.
- **구현 첫 단계에서 1편 화질·부드러움과 비교해 검증**한다. 부족하면 예비안: 운영체제별 캡처(Windows `gdigrab`/`ddagrab`, Mac `avfoundation`, Linux `x11grab`) + 화면 배율 자동 감지.
- 8K처럼 실시간 전송이 버거운 해상도는 "한 장씩 멈춰 가며 찍기"(가상 시간) 방식.

### 5.4 로그인·비밀번호
- 시연 중 비밀번호 칸(type=password)은 **값을 기록하지 않는다.** 표에는 `🔒 비밀번호`.
- 처음 한 번 "저장할까요?" → PC 안 비밀 보관함(운영체제 키체인/자격 증명 관리자, 없으면 `.env`)에만 저장. 장면 표·영상·내보내기·공유 파일 어디에도 남지 않음.
- 녹화 시 보관함에서 꺼내 입력, 화면에는 `●●●●` + 흐림.
- **시작상태**: 로그아웃(로그인 편) / 로그인(이후 편, 녹화 전에 미리 로그인하고 관리자 화면부터 녹화).
- 로그인 실패, 인증번호, 로봇 확인(캡차)은 **멈추고 사람에게 입력을 부탁**한다.
- 자동 접속을 막는 사이트는 로그인만 사람이 하고 이후 조작을 이어받는다.

### 5.5 그 밖의 녹화 기능
- **팝업·쿠키 안내·채팅 버튼 자동 닫기/숨기기**
- **마우스 올리면 열리는 메뉴**(드롭다운) 지원
- **보여 주기 장면**: 클릭 없이 강조 상자, 천천히 스크롤하며 보여 주기
- **완료 화면 처리**: 저장 차단 때문에 완료 화면이 없을 때(1편 문제) → ① 테스트용 주소 지정, ② 사람 확인 후 그 장면만 실제 실행. 확인 없이 실제 저장·발송은 절대 안 함
- **로딩 대기**: 페이지·애니메이션이 끝날 때까지 기다리고, 로딩 구간은 편집에서 빨리 감기
- **같은 장면 표로 PC·모바일 둘 다**: 모바일은 기기 흉내(아이폰·갤럭시 화면 크기, 터치), 커서 대신 터치 표시, 세로 출력

## 6. 편집·출력

- 편집은 `screenfx` 그대로(배경, 확대, 카메라, 디밍, 클릭 파동, 빨리 감기, 흐림). 클릭 정보를 프로그램이 직접 기록하므로 판단 없이 계산으로 처리.
- 인트로·아웃트로·자막·진행 표시·말풍선·챕터는 `build_ep1.py` 를 일반화(제목·단계·브랜드를 입력으로).
- **화질**: 기본 1440p60(1편 기준). 1080p(빠르게) 선택 가능. **4K·8K는 기능으로만 넣고 화면에는 드러내지 않음** — 고급 설정에서만. 4K는 배율 2로 찍어 진짜 4K로(늘린 것 아님). 8K는 "실험용", 시간이 매우 길고 유튜브 외에는 의미 없음.
- 플랫폼별 내보내기는 각 플랫폼이 실제로 보여 주는 최대 화질에 맞춰 자동으로 줄인다.
- **코덱**: 업로드용 전부 **H.264**(MP4, AAC 48kHz, faststart, BT.709, yuv420p, 일정 프레임). 내 웹사이트용만 **AV1 + H.264 예비**. 녹화 원본(작업용)은 무손실.
- 글꼴은 무료 한글 글꼴을 프로그램에 동봉해 OS와 무관하게 같은 모양(라이선스 확인).
- 기본은 CPU 인코딩으로 결과를 통일, 그래픽카드 가속은 선택.
- **빠른 미리보기**: 최종본 전에 저화질로 1~2분 만에 확인.

## 7. 목소리

- 기본 현수 차분(edge-tts, 무료, 인터넷 필요). 선택지: 다른 AI 목소리, **내 목소리로 녹음**(문장이 하나씩 뜨고 읽으면 잡음 정리·길이 맞춤), **목소리 없이 자막만**, 유료 음성 API(키 넣으면 목록에 추가), 다른 언어 목소리.
- [▶ 듣기]는 장면 표의 **실제 첫 문장**을 그 목소리로 들려줌. 만든 소리는 저장해 재사용.
- **발음 자동 검사**: 생성 후 받아쓰기로 다시 듣고, 다르게 들린 단어를 빨갛게 표시하고 띄어쓰기 수정을 제안("태권월드"→"태권 월드").
- 상업적 사용·배포 시 Microsoft 음성 이용 조건 확인 안내.

## 8. 결과·내보내기

### 8.1 동작
- **올릴 곳만 고르면** "올릴 곳 → 필요한 항목" 연결표에 따라 아래 항목이 자동으로 켜지고 꺼진다. 사람은 빼고 싶은 것만 끈다.
- **빠짐 검사**: 빠진 것, 글자 수 초과, 썸네일 크기 오류를 내보내기 전에 표시.
- 플랫폼별 폴더(`유튜브/`, `릴스/`, `웹사이트/` …)에 파일과 **복사해 붙여 넣을 글**을 정리.
- 어디에 언제 올렸는지 체크하는 기록, 플랫폼 안에서만 되는 설정(유튜브 최종 화면·카드, 예약 시각 등) 체크리스트.
- 올리기는 사람이 한다(자동 업로드는 계정 연결·실수 위험 때문에 기본에서 제외, 나중 선택 기능 후보).
- **올릴 곳 목록**: 유튜브, 유튜브 쇼츠, 네이버 클립, 네이버 블로그, 인스타 릴스, 인스타 피드, 틱톡, 페이스북, 링크드인, X, 스레드, 핀터레스트, 내 웹사이트, 이메일·메신저.

- 자막 항상(소리 없이 보는 사람), 화면 꽉 채우는 비율, 가리는 영역 피하기

- 넉넉한 화질의 업로드 파일
- 썸네일 2~3개 생성(유튜브 썸네일 비교용)

- 단계별 글(화면 캡처 + 문장), 대본 전문, 자주 묻는 질문 초안
- 구조화 데이터: VideoObject, HowTo, 핵심 구간(Clip, SeekToAction)
- 영상 사이트맵 항목, 이미지 대체 텍스트, 오픈그래프·X 카드 정보
- 영상 전용 페이지 틀, 질문형 제목, 단계별 요약 문단
- **다국어**: 여러 언어 자막, 언어별 제목·설명, 유튜브 다국어 음성 트랙, 언어별 페이지 연결(hreflang). 번역은 AI 도우미 또는 직접(기계 번역만이면 어색할 수 있음 안내)

### 8.5 웹페이지 속도
- AV1(1080p) + H.264 예비 + 포스터 이미지(AVIF/WebP)
- 붙여 넣기 코드: AV1 지원 시 AV1, 아니면 H.264 자동 선택, **누르기 전에는 내려받지 않음**(preload none, 포스터)
- 유튜브 삽입은 썸네일만 먼저 보여 주고 누르면 재생기가 뜨는 가벼운 방식

## 9. 브랜드 설정

- 위치: 오른쪽 위 ⚙ 설정 → **브랜드** 탭(0.1의 5번). 규칙은 같은 창의 **규칙** 탭.
- 여러 브랜드 저장(고객사마다), 영상 만들 때 고르기. 브랜드 파일 내보내기/가져오기.
- **빠른 시작**: 사이트 주소로 로고·색·이름 자동 추출, 로고 그림에서 색 추출.
- **기본**: 브랜드 이름(표기), **읽는 이름**(발음, 예 "태권 월드"), 로고(가로형·정사각형), 주 색·강조 색·포인트 색, 글꼴(제목·자막).
- **목소리·말투**: 기본 목소리·빠르기, 말투(차분/친근/전문), 고정 인사말·끝인사, 표현 바꾸기 목록.
- **영상 꾸미기**: 인트로·아웃트로 틀과 길이, 배경 모양, 자막 위치·상자, 확대·디밍 정도, 클릭 효과, 배경음악 기본값, 워터마크.
- **내보내기 글**: 설명 끝 고정 문구(주소·문의처), 기본 해시태그, 행동 유도 문구, 썸네일 글자 스타일.
- **읽힘 검사**: 글자가 배경에 묻히면 같은 색 계열에서 밝기만 조정하고 알림. 색은 배경·강조·포인트 세 역할로만 사용.
- 가로·세로 영상, 썸네일, 웹 포스터, 설명서까지 같은 색·글꼴.
- 태권월드 기본값: 배경 `#1B2559 → #405BEA`, 강조 `#CC1424`, 1편 포인트 `#54B4CC`.

## 9.1 참고 영상 스타일 따라 하기

- 참고 영상 파일(또는 허용되는 링크)을 넣으면 **편집 기법만** 분석해 "스타일 카드"로 정리하고, 꾸미기에서 고르면 그 스타일로 만든다. 한 번 분석한 카드는 저장해 재사용.
- AI 없이 뽑는 것: 비율·해상도·프레임, 장면 전환 간격(속도감), 확대·이동 빈도와 배율(움직임 분석), 전환 방식(컷/페이드/밀기), 자막 위치·크기·색·상자(OCR + 위치), 색감, 말 빠르기·쉼(받아쓰기), 배경음악 유무·크기, 인트로·아웃트로 길이.
- AI 도우미가 있을 때만: 클릭 효과·강조 상자·말풍선 모양, 전체 구성과 말투.
- **우리 엔진이 가진 기능 범위 안에서만** 맞춘다. 3D 효과, 수작업 모션 그래픽 등은 카드에 "따라 할 수 없음"으로 표시.
- **스타일만, 내용은 가져오지 않음**: 참고 영상의 화면·음악·로고·문구는 쓰지 않는다(저작권).
- **링크**: 플랫폼 약관상 내려받기가 막힌 경우가 많아, 기본은 본인 영상이거나 허락받은 영상 **파일 올리기**. 링크는 약관상 허용될 때만 쓰도록 안내.
- **섞이지 않게 하는 적용 순서**(아래가 위를 덮어씀, 바꾸는 범위가 다름):
  1. 1편 기본 규칙(기준) — 스타일 카드를 고르지 않으면 이것만 적용, 1편과 동일
  2. 참고 영상 스타일 — **편집 기법만**(속도감, 확대 빈도·배율, 전환, 자막 모양·위치, 말 빠르기, 인트로 길이)
  3. 브랜드 — **색·로고·글꼴·목소리·인사말**(참고 영상의 색보다 우선. 참고 영상 색을 쓰려면 직접 선택)
  4. 이번 영상만 — 사용자가 직접 바꾼 값
  - **안전 규칙(개인정보 흐림, 저장·발송 차단)은 어떤 층도 끌 수 없다**(끄려면 규칙 화면에서 경고 후).
  - 장면 표(무엇을 누르고 무엇을 말할지)와 내보내기 연결표는 스타일과 무관.

## 10. 규칙

- 지금 `RULES.md` 에 글로 적힌 규칙을 **화면에서 고칠 수 있는 설정**으로 바꾼다. 위치: ⚙ 설정 → **규칙** 탭.
- **3층**: 기본 규칙(1편 기준, [기본값으로 되돌리기]) ← 브랜드 규칙 ← 이번 영상만. 아래 층이 위를 덮어쓰고, 기본 규칙은 그대로 남는다.
- 항목: 목표 길이(1분 30초)·최대(3분), 한 문장 최대 글자, 문장 하나 = 동작 하나, 문장 사이 쉼(0.45~0.55초), "눌러 주세요" 뒤 쉼, 표현 바꾸기, 확대(1.6, 최대 2.0), 디밍(30%), 안전(개인정보 흐림·저장 차단).
- **적용 방식**: 자동으로 고치는 규칙(표현 바꾸기, 읽는 이름, 쉼, 확대·디밍) / 경고만 하는 규칙(긴 문장, 길이 초과, 안심 문장 없음) / 잠긴 규칙(개인정보 흐림, 저장 차단 — 끌 수 있지만 매번 경고, 기본 켜짐).
- 플랫폼 규칙(8.2, 8.3)은 별도 파일.

## 11. AI 도우미 (기본 포함, 선택 사용)

- 시작 화면에 [한 번 해 보이기]와 나란히 **[AI에게 맡기기]**.
- 키가 없으면 그 자리에서 3단계 안내: ① 키 받는 곳 열기 ② 붙여 넣기 ③ 확인 → 연결됨. 키는 PC 안에만 저장, 다시 묻지 않음.
- 한 줄 요청 → AI가 Playwright로 사이트를 둘러보며 순서를 알아내 장면 표와 문장을 채운 채 확인 단계로. 둘러볼 때도 저장 차단·개인정보 흐림 동일. 로그인·인증은 사람에게 물어봄.
- 실행 전 예상 비용 표시. 키가 없으면 이 기능만 꺼지고 나머지는 그대로.
- 그 밖의 용도(모두 선택): 문장 다듬기(브랜드 말투), 번역, 제목·설명 다듬기.
- 구현: Claude 호출은 `autoedit/llm.py` 래퍼 경유(기본 모델은 CLAUDE.md 규칙, 구조화 출력은 pydantic + `output_format`). 다른 제공자(Gemini 등) 키도 받을 수 있게 열어 둔다.

## 12. 품질·안전 장치 (1편 때 사람이 하던 확인을 프로그램이)

- **리허설**: 녹화 전 모든 대상 확인.
- **발음 자동 검사**(7절).
- **자동 검수 보고서**: 완성 후 장면별 사진과 함께 주소창·브라우저 테두리 노출, 디밍·클릭 파동 위치와 실제 버튼 일치, 자막 오타·단계 표시 구간, 영상·오디오 길이 일치, 의도치 않은 오류 메시지 점검(`RULES.md` 9절 체크리스트를 자동화).
- **개인정보 최종 검사**: 완성 영상을 글자 인식(OCR, `autoedit/privacy.py` 재사용)으로 훑어 전화번호·이메일 등이 보이면 경고.
- 개인정보 칸 자동 감지(이름·전화·생년월일·주소·이메일 등 라벨과 입력 형식으로) + 수동 추가.
- 실제 저장·발송·결제는 확인 없이 절대 실행하지 않음. 데모 계정 사용 원칙 안내.

## 13. 운영 기능

- **부분 다시 찍기**: 사이트가 바뀌면 바뀐 장면만 다시 녹화.
- **사이트 변경 감지**: 저장된 장면 표로 리허설만 다시 돌려 바뀐 장면을 알림.
- **여러 편 한꺼번에 만들기**: 장면 표 여러 개를 걸어 두고 순서대로.
- **중간에 꺼져도 이어서**: 단계별 중간 결과 저장.
- **시리즈 관리**: 여러 편 목록, 아웃트로 "다음 편 안내" 자동 연결.
- **용도별 시작 틀**: 고객 안내 / 직원 교육 / 제품 소개(인트로 문구·말투·길이).
- **따라 하기 설명서 자동 생성**: 화면 캡처 + 문장으로 PDF·웹 문서.
- **프로젝트 파일 공유**: 장면 표·브랜드·설정을 파일 하나로(비밀번호 제외).
- **오류 보고 묶음**: [오류 정보 복사] 한 번으로 AI·개발자에게 물어볼 수 있게(개인정보·키 제외).
- **업데이트**: 실행 시 새 버전 알림, 버튼 하나로 업데이트.
- **휴대폰 리모컨(나중)**: PC에서 도는 프로그램을 같은 와이파이의 휴대폰 브라우저로 조작.

## 14. 실행 환경

- Windows·Mac·Linux. 부품(Python, Playwright, Chromium, ffmpeg, edge-tts)은 모두 크로스플랫폼.
- 설치: `setup.bat`(winget) / `setup.sh`(brew, apt). Playwright Chromium 설치 추가.
- 실행 파일: `튜토리얼.bat` / `튜토리얼.command` / `tutorial.sh`.
- 인터넷은 **사이트 접속**과 **목소리 생성**(문장만 전송)에만. 영상·보관함·장면 표·브랜드는 PC 밖으로 나가지 않음. AI 도우미를 켰을 때만 AI 제공자로 요청이 나감.
- 프록시 환경(클라우드 세션 등)에서는 Chromium에 프록시 CA 등록(`RULES.md` 7절). TLS 검증은 끄지 않는다.
- 휴대폰·태블릿에서 직접 실행은 불가(리모컨 방식만). 웹이 아닌 PC 프로그램·휴대폰 앱의 자동 조작은 범위 밖.

## 17. 한계·주의 (사용자에게 그대로 안내)

- 프로그램은 "보여 준 대로 스스로 들어가서 만든다". **"어떻게 하는지 스스로 알아내기"는 AI 도우미를 켰을 때만.**
- 알고리즘 노출, 검색 인용은 **보장할 수 없다.** 조건을 빠짐없이 갖추는 것까지.
- 플랫폼 규격·규칙은 구현 시점 기준. 바뀌면 설정 파일 갱신.
- 사이트가 크게 바뀌거나 프로그램 오류는 코드 수정이 필요할 수 있다(오류 보고 묶음으로 AI에 문의).
- 캡차, 문자 인증, 자동 접속 차단 사이트는 사람 도움 필요.
- 녹화 대상은 본인 사이트이거나 사용 권한이 있는 사이트. 고객사 사이트는 허락을 받고. 실제 고객 정보가 있는 계정 사용 금지.
- AI 음성(edge-tts), 배경음악, 글꼴의 상업적 이용·배포 조건 확인.
- AI 생성 표시: 실제 사이트 화면 녹화 + AI 목소리인 사용법 영상은 보통 플랫폼의 표시 대상(실제처럼 지어낸 사람·사건)이 아니어서 기본 항목에서 뺐다. 플랫폼 정책이 바뀌면 확인.
- Windows는 사용자 PC에서, Mac은 Mac 사용자가 한 번 실기 확인해야 한다.

## 18. 확인이 필요한 것 (구현 전·중)

- CDP 화면 전송이 1440p60 품질을 내는지(16절 1단계)
