# 6단계 검사: 로그인 편 (어떤 사이트에서든)

튜토리얼 메이커는 태권월드 전용이 아니라 어떤 웹사이트든 쓰는 프로그램이라, 6단계(로그인·보관함·시작상태·완료 화면·메뉴·보여 주기)는
연습용 사이트(`tutorials/sample_site`, 푸른숲 도서관 사서 화면)로 확인했습니다. 태권월드 2편은 데모 계정을 받으면 같은 방법으로 만듭니다.

```bash
python -m http.server 8765 -d tutorials/sample_site
python tutorials/login_check/run_login.py
```

흐름: 시연(공지 닫기 → 사서 로그인 → '회원 관리' 메뉴에 마우스 → '회원 등록' → 이름·휴대전화·인증요청 → 인증번호 → 저장) →
확인(🔒 비밀번호 한 번 저장, 보여 주기 장면 추가, 마지막 장면 '확인 후 실제 실행') → 만들기(녹화 중 인증번호 질문에 답) → 결과 →
'로그인한 상태에서'로 바꿔 빠른 미리보기. 화면 사진은 `shots/`.
