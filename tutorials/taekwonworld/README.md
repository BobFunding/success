# 태권월드 처음 시작하기 시리즈 — 2~5편 만든 스크립트

튜토리얼 메이커 엔진(`autoedit/tutorial`)에 편마다 필요한 동작(파일 올리기, 안내 창, 저장 막기, 흐림)을 더한 스크립트입니다.
1편은 `tutorials/ep1/` 의 장면 표만으로 만듭니다.

## 방향 (사용자 결정, 2026-10-13)
- **목적**: 처음 온 관장님이 헤매지 않게. 순서는 사이트 첫 화면 안내 창('태권월드가 처음이신가요?')의 권장 순서.
- **영상 순서·말은 공식 사용자 가이드(https://taekwonworld.net/guide)와 같게.** 만들기 전에 해당 가이드 항목을 먼저 읽는다.
- 편 번호는 이어서 쓰고, 파트는 묶음 이름으로만 붙인다.

| 파트 | 편 | 폴더 | 가이드 |
|---|---|---|---|
| 1. 시작하기 | 1편 회원가입·로그인 ✅ · 2편 도장 등록 ✅ | `../ep1`, `ep2` | 회원가입 & 로그인 / 도장 & 결제선생 등록 |
| 2. 도장 뼈대 만들기 | 3편 반 만들기 ✅ · 4편 급띠 체계 ✅ | `ep3`, `ep4` | 반 등록 / 급·띠 체계 설정 |
| 3. 사람 모으기 | 5편 사범님 초대·반 배정 ✅ · 6편 수련생 등록 · 7편 수련생·학부모 초대 | `ep5` | 초대장 발송 / 소속반 추가 / 수련생 등록 |
| 4. 운영 시작 | 8편 차량 등록 · 출결 · 납부 | | |

## 실행
```bash
# 계정: 아이디는 환경변수로, 비밀번호는 보관함(튜토리얼 메이커에서 한 번 저장) 또는 TUTORIAL_SECRET 환경변수로.
export TW_DEMO_ID=<데모 계정 아이디>
python tutorials/taekwonworld/ep5/run_ep5.py check            # 리허설만(녹화 없이 누를 곳을 다 찾는지)
python tutorials/taekwonworld/ep5/run_ep5.py make --fast      # 목소리 → 녹화 → 편집 → 검수
#   작업 폴더 기본값: output/taekwonworld/ep5 (커밋하지 않음). 다른 곳에 두려면 make <폴더>
#   --silent : 목소리 없이 자막만
```
- Windows: `.venv\Scripts\python.exe tutorials\taekwonworld\ep5\run_ep5.py make --fast`
- 3·4·5편은 `ep3/run_ep3.py`(→ `ep2/run_ep2.py`)를 불러 쓴다. 폴더 구조를 그대로 둘 것.
- 아이디가 들어간 장면 표 사본은 임시 폴더에만 만든다(저장소에 남기지 않음).

## 안전 장치 (지키는 것)
- **실제로 저장·발송하지 않는다.** 편마다 `요청차단` 화면에서 쓰기 요청을 막는다(읽기 요청 `…read…` 는 통과).
  리허설(`check`)이 막힌 요청을 확인해서, 안 막혔으면 멈춘다.
  2편 도장 등록 · 3편 classcreate · 4편 levelinfoupdate · 5편 invite_teacher_multi, instructorcreatebytitle.
- 안내 창의 **'다시보지않기'는 누르지 않는다**(계정 설정이 바뀜). `팝업닫기: false`.
- **흐림**: 아이디·비밀번호·번호 칸, 다른 도장 카드, 첫 화면 차량번호·수련생 이름·전화, 반 화면 창 안의 사람 이름.
- 결과 화면은 실제 저장 대신 이미 있는 같은 이름의 데이터를 보여 준다(예: 3편의 'A반 오후 2시').

## 편마다 알게 된 것 (함정)
- 2편: 파일을 올리면 먼저 적은 칸이 지워짐(사이트 버그) → 파일·로고·직인 먼저. 주소 검색 창은 sync Playwright 의 time.sleep 중 route 가 멈춰 빈 창 → `wait_for_timeout` 으로 기다림.
- 3편: 반 목록 읽기도 POST(classreadbyday). 시간 칸은 react-datepicker 목록이라 목록까지 밝게.
- 4편: 급수가 비거나 겹치면 저장 안 됨('중복된 급수가 존재합니다') → 위쪽 급수를 하나씩 올리는 장면을 넣음. 마무리 문장은 2개까지만 들어감.
- 5편: 안내 창 '사범님 초대, 반 배정'은 /invitation/send/teacher 로 바로 감. 반 정보 창 위에 담당 추가 창이 겹쳐서, 체크박스는 '담당 사범님 추가' 창 안에서만 찾는다.
- 공통: 로그인 뒤 바로 /home 으로 가는 경우가 있어 도장 고르기는 /dojang/select 로 직접 가서 '태권월드 태권도장'을 누른다(`run_ep3.run_pre`).
- 목소리: 2026-10-10 부터 Microsoft 음성 서버 주소가 바뀜 → `autoedit/narration.py` 가 새 주소·예전 주소를 차례로 시도.
