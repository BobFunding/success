28편을 올릴 때 복사해서 붙여 넣기만 하면 되도록 정리했어요. 제목은 검색어부터, 설명 첫 두 줄은 AI가 그대로 인용할 수 있는 답, 모든 영상은 태권월드 홈페이지와 사용자 가이드로 연결돼요.

  1. 채널 정보를 한 번만 채워요 (아래 1번)
  2. 재생목록 10개를 먼저 만들어요 (2번)
  3. 편마다 영상·자막을 올리고 칸을 복사해요 (3번)
  4. 고정 댓글을 달고 '올림'에 체크해요

1. 채널 설정 (한 번만)

YouTube 스튜디오 → 맞춤설정 → 기본 정보

업로드 기본 설정 (설정 → 업로드 기본설정에 한 번 저장해 두면 편마다 안 바꿔도 돼요)

  • 공개 상태공개 (검색·AI 인용을 받으려면 공개)
  • 카테고리노하우/스타일
  • 동영상 언어 · 자막 언어한국어
  • 시청자층아니요, 아동용이 아닙니다 (관장님 대상)
  • 퍼가기 허용켜기 (나중에 가이드 페이지에 넣으려면 필수)
  • 자동 챕터켜기 (설명란 챕터가 우선)

2. 재생목록 10개

전체 1개 + 파트 9개. 영상을 올릴 때 '전체'와 해당 파트 두 곳에 넣어요

3. 편별 업로드 (28편)

편을 누르면 펼쳐져요. 순서대로 올리면 이전·다음 편 안내가 맞아요

다 올린 뒤에 할 일

  1. 홈페이지 맨 아래와 회사 소개 정보(구조화 데이터 sameAs)에 유튜브 채널 주소를 넣어 달라고 개발자에게 전달해요. 채널과 사이트가 서로를 가리켜야 같은 회사로 묶여요.
  2. 개발자가 가이드 페이지를 고치면, 페이지마다 해당 영상을 넣고 영상 정보(VideoObject)를 붙여요. 설명란의 '글로 보는 단계별 안내' 주소가 그 페이지예요.
  3. 네이버 블로그에도 편마다 영상과 요약 글을 올리고 같은 가이드 주소를 달아요.
  4. 가이드 항목이 없는 편(12~14, 16~19편)은 지금 사용자 가이드 첫 화면으로 연결돼 있어요. 전용 가이드 페이지가 생기면 그 주소로 바꿔요.
