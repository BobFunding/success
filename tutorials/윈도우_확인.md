# Windows PC 에서 확인하기 (10단계)

클라우드(Linux)에서는 모두 확인했지만, **실제 Windows PC** 에서 한 번 돌려 봐야 끝나는 단계예요. 아래 순서대로 해 주시고 결과만 보내 주세요.

1. GitHub 에서 최신 폴더 받기(이미 있으면 [업데이트] 또는 `git pull`).
2. `setup.bat` 더블클릭 → "설치 완료!" 까지. **막힌 곳이 있으면 그 창의 마지막 몇 줄을 사진으로** 보내 주세요.
3. `튜토리얼.bat` 더블클릭 → 브라우저에 화면이 뜨는지.
4. ⚙ 설정 → 규칙 → **🩺 자가 점검 → [점검하기]**(약 5분) → [결과 복사] → 보내 주기.
5. 시간이 되면 **[1편 재현까지]**(30분 이상, 인터넷 필요) → [결과 복사] → 보내 주기.
   - 이 PC 에서 1편을 만들어, 클라우드에서 검사를 통과한 기준 기록과 비교해요.
     누른 자리 8px·장면 안 박자 0.35초·문장 길이 0.15초·영상 길이 1초 안이면 통과.
6. (선택) 실제로 한 편: 시작 화면에서 우리 사이트 주소 → [한 번 해 보이기] → … → [만들기]. 이상한 점은 [📋 오류 정보 복사].

Mac 사용자가 있으면 `bash setup.sh` → `튜토리얼.command` 로 같은 순서(4·5번)를 부탁해 주세요.

## 왜 이렇게 확인하나요
원래 1편 코드는 Linux 가상 화면(Xvfb)에서만 녹화돼서, Windows 에서는 '원래 코드와 같은 때 나란히 찍어 비교'를 할 수 없어요.
그래서 클라우드에서 통과한 기록(`tutorials/ep1/reference/`)을 기준으로 삼고, 운영체제마다 글꼴이 조금 달라 생기는 몇 px 은 허용합니다.
