# 🎬 유튜브 자동 편집기

영상을 올리면 아래 순서로 자동 편집합니다.

1. **1차 컷 편집**: 무음 구간과 필러워드("어", "음")를 잘라냅니다. 자연스러운 쉼(기본 0.45초 이하)은 남기고, 애매한 말("그", "이제", "아" 등)은 Claude가 문맥을 보고 의미가 있으면 남깁니다.
2. **설명 일러스트**: 대본을 읽고 이해를 돕는 지점(개념, 과정, 비교, 숫자)을 골라 *플랫 벡터 + 핸드드로잉 카툰* 스타일 그림을 글자를 최소화해서 넣습니다. 그림은 GPT 이미지로 여러 장을 동시에 만듭니다. 복잡한 내용은 전체 화면으로, 간단한 내용은 화자 옆 카드로 넣습니다.
   - 장면 전환: 카드는 페이드와 함께 화면 가장자리에서 부드럽게 미끄러져 들어오고, 전체 화면 그림은 페이드 중에 천천히 확대됩니다. 컷 경계의 오디오에는 짧은 페이드를 넣어 '틱' 소리를 없앱니다.
3. **개인정보 처리**: 화면에 보이는 전화번호, 이메일, 주소, 계좌, 차량번호, 이름, 아이디는 **모자이크**로, 말로 나온 개인정보는 **삐-** 소리로 가립니다.

## 처음 한 번만

**새 컴퓨터에서는 `setup.bat` 을 더블클릭하세요.** Python 3.12, FFmpeg, 가상환경(`.venv`), PyTorch(그래픽카드가 있으면 GPU 버전), 필요한 패키지를 자동으로 설치하고 `.env` 파일을 만듭니다. 10~30분 걸릴 수 있고, 끝나면 `web.bat` 으로 실행합니다.
`.venv` 는 컴퓨터마다 따로 만들어야 해서 GitHub 에 올라가 있지 않습니다. 그래서 GitHub 에서 받은 폴더는 `setup.bat` 없이는 `web.bat` 이 동작하지 않습니다.

1. `.env.example` 파일을 복사해 `.env` 로 이름을 바꾸고 API 키를 넣습니다.
   ```
   ANTHROPIC_API_KEY=sk-ant-...   # 컷 판단, 일러스트 기획, 개인정보 판단
   OPENAI_API_KEY=sk-...          # 일러스트 그림 생성 (GPT 이미지, 여러 장 동시 생성)
   ```
   OpenAI 키가 없으면 일러스트는 Claude가 SVG로 그리는 방식으로 자동 전환됩니다.
   키가 없어도 실행은 됩니다. 다만 무음 제거, 확실한 필러 제거, 정규식 기반 개인정보 처리만 동작하고 일러스트는 건너뜁니다.
2. 첫 실행 때 Whisper 음성인식 모델(약 3GB)과 OCR 모델을 자동으로 내려받습니다.

## 사용법

**웹 화면 (추천)**: `web.bat` 을 더블클릭하면 브라우저가 열립니다. 영상을 올리고 **자동 편집 시작**을 누르세요.
- 웹 화면을 켜 둔 채로 코드나 설정을 고치면 **저장하는 순간 자동으로 반영**됩니다(자동 새로고침 모드). `.env` 의 API 키도 편집을 시작할 때마다 다시 읽습니다.
- 단, 영상을 처리하는 도중에 코드를 저장하면 진행 중인 작업이 끊길 수 있습니다.

**명령줄**
```bash
.venv\Scripts\python.exe run.py 내영상.mp4
.venv\Scripts\python.exe run.py 내영상.mp4 --allow "내이름,채널명" --illust-every 30
.venv\Scripts\python.exe run.py 내영상.mp4 --terms "복리,단리,ETF"   # 주제 용어 힌트
```

- **한국어·영어가 섞인 영상**: `--lang ko+en` → 언어마다 받아 적고 구간별로 더 잘 들린 쪽을 고릅니다.
- **번역 자막**: `--translate ko` → 외국어 문장을 한국어로 번역해 크게, 원문은 아래 작게 화면에 입힙니다(`translations.json` 을 고친 뒤 `--rerender` 가능). 자막은 기본으로 화면에 입혀지고 `subtitles.srt` 도 따로 나옵니다.
- **GPU 없는 PC에서 4K**: `--x264-preset veryfast` 로 렌더링 시간을 크게 줄일 수 있습니다.
- **화면 녹화 편집 (Screen Studio 스타일)**: `python -m autoedit.screenfx 녹화.mp4 결과.mp4` → 그라데이션 배경 + 둥근 모서리 + 그림자, 작업하는 곳으로 부드럽게 자동 줌, 대기 구간 빨리 감기. 클릭 기록(`--clicks clicks.json`, `[{"t": 초, "x": px, "y": px}]`)이 있으면 클릭 위치로 줌하고 클릭 파동을 그립니다. 커서 크기 변경·떨림 보정은 커서가 영상에 박혀 있어 할 수 없습니다.
- **받아쓰기 교정**: Claude 키가 있으면 받아쓰기 직후 Claude가 주제 용어와 문맥을 보고 잘못 받아 적은 단어를 고칩니다(예: "단리"의 실제 발음 [달리] 때문에 "달리는"으로 적힌 것 → "단리는"). 고친 내역은 `report.md` 에 남습니다. 끄려면 `--no-correct`.

## 결과물 (`output/영상이름_날짜시간/`)

| 파일 | 내용 |
|---|---|
| `2_final.mp4` | 최종본 |
| `1_cut.mp4` | 컷 편집만 된 버전 |
| `subtitles.srt` | 자막 (유튜브에 바로 업로드 가능) |
| `illustrations/` | 생성된 일러스트 (SVG 원본 + PNG) |
| `report.md` | 무엇을 자르고, 넣고, 가렸는지 기록 |
| `edit_plan.json` | 모자이크/삐-/일러스트 목록 |

### 검수 후 다시 렌더링하기
자동 감지가 틀린 부분이 있으면 `edit_plan.json` 에서 해당 항목을 지우거나 시간을 고친 뒤 최종본만 다시 뽑을 수 있습니다. 컷 편집과 AI 호출은 다시 하지 않습니다.
```bash
.venv\Scripts\python.exe run.py --rerender output\내영상_20261005_120000
```
일러스트 SVG를 직접 고쳤다면 PNG도 같이 바꿔주세요.

## 주의

- **개인정보 감지는 100%가 아닙니다.** 업로드 전에 `report.md` 의 목록과 최종본을 꼭 직접 확인하세요. 얼굴 모자이크는 아직 지원하지 않습니다.
- Claude API 비용은 10분 영상 기준 대략 수천 원 수준입니다(대부분 일러스트 생성 비용이며, 일러스트 수와 자동 검수 여부에 따라 달라짐). 비용을 줄이려면 `--no-review` 를 쓰거나 일러스트 빈도를 낮추세요.
- NVIDIA GPU가 있으면 자동으로 사용합니다(음성인식, OCR, 인코딩). 없으면 CPU로 동작하며 느립니다.
